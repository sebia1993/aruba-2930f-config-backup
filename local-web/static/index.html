      포트·PoE 관리에서 변경

      
          
      
          
      진단을 시작하면 스위치의 이전 케이블 측정값을 지우고 선택한 포트를 새로 측정합니다.
      
        
      
      
      
      
      
        
      진단 결과
      
        
      대상 포트를 선택하고 케이블 진단을 실행하세요.
      
      
      
    
      
    
      
      
      Ping 테스트
      스위치에서 목적지까지의 통신 상태를 측정합니다.
      
      
      
      
      
        
      측정 대상 및 옵션
      
        
      
          
          
      
          
          
          
      Ping을 보낼 스위치의 IPv4 주소를 줄마다 입력합니다. SSH 포트 기본값은 22입니다. 다른 포트를 쓰는 장비에는 주소 뒤에 포트를 지정하세요. 같은 IP와 SSH 포트 조합은 한 번만 등록합니다.
      
          
          
          
      ICMP 응답을 확인할 서버의 IPv4 주소를 한 줄에 하나씩 입력하세요. 탭 뒤의 이름은 결과에 표시합니다. NMS로 보내는 Ping이 성공해도 SNMP·Syslog 등 개별 서비스 상태는 별도로 확인해야 합니다.
      
          
      
          
      
            
            
      열 제목과 장비 행을 함께 붙여넣으세요. 입력한 GW·BB·NMS만 각 스위치에서 측정합니다.
      
            
      
            
      열 연결 확인 · 변경
              
      
            
      
            
      장비·목적지 선택
      
              
      측정할 목적지
      
                
                
                
              
      
              
      
              
      
            
      
          
      
          
      
            
      
              
              
              
            
      
            
      연속 측정은 한 명령으로 목적지마다 1~100회 전송합니다. 간격을 지정하면 목적지마다 한 번씩 전송하고 시각별 결과를 기록합니다. 최대 10,000회, 전체 200,000회까지 설정할 수 있습니다.
      
            
      
            
      
            
      Ping 시작을 누르면 스위치 SSH 계정을 확인하고 측정을 시작합니다.

      측정 옵션
      
          
      
            
            
            
            일반 확인
          
      
          
      
            
      
              
              
      각 요청의 응답을 기다리는 제한입니다. 장비 범위는 1~60초, 장비 기본은 5초입니다. 일반 사내망 점검의 화면 기본은 timeout 2입니다. 전송 간격과 실제 응답 지연은 별도로 측정합니다.
      
            
      
              
              
      관리망 경로를 점검할 때에는 각 스위치의 SSH 접속 IP를 출발지로 지정합니다. 스위치 자동 선택은 Source 옵션을 생략합니다. 직접 IP는 장비마다 입력하고, VLAN은 유효한 IPv4가 있는 VLAN을 선택합니다. 예를 들어 source 10은 VLAN 10을 지정합니다. 지정값 소유 여부를 확인할 수 없으면 해당 조합에 오류를 표시합니다.
      
            
          
      
          
          
      
            
            
      
            
            
      측정 간격은 같은 목적지에 다음 Ping을 보내기까지의 목표 시간입니다. SSH 준비나 다른 작업 대기로 간격이 늘어날 수 있습니다. 일시정지 중에도 최대 측정 시간은 흐릅니다.
      
          
      
          
      고급 Ping 옵션 
      
            
      
              
              
      ICMP 데이터 영역의 크기입니다. 장비 범위는 0~65,471바이트, 기본값은 0입니다. 화면은 기본적으로 옵션을 생략합니다. data-size 1472에 IPv4·ICMP 헤더 28바이트를 더하면 1500바이트입니다. 단편화될 수 있어 큰 패킷의 성공만으로 경로 MTU를 확정할 수 없습니다.
      
            
      
              
              
      연속 측정은 기본 10대를 함께 검사하고, 한 장비가 끝나면 다음 장비를 시작합니다. 장비마다 GW·BB·NMS용 SSH 세션을 따로 엽니다. 간격을 지정하면 전송 속도 제한도 함께 적용됩니다.
      
          
      
          
      
        
      
      
      
      
      
        
      명령 미리보기
        
      
        
      입력을 작성하고 미리보기를 실행하세요.
      
        
      
          
      
            
      
          
      
            
      
        
      
      
      
      
      
        
      측정 진행 및 결과
      
        
      
          
      시작하면 스위치에서 실제 읽기 전용 Ping을 실행합니다. 요청 ID를 보관하며 연결이 끊겨도 새 요청으로 자동 재실행하지 않습니다.
      
          
      
          
      현재 작업 확인 중
      
          
      요청 ID: —
      
          
          
      아직 확인된 측정 결과가 없습니다.
      
          
      
            
            
            
          
      
          
      
          
      
          
      
            
            
            
            
          
      
          
      원래 작업의 옵션으로 새 측정을 시작합니다. 실패 재실행에는 일부 손실, 무응답, 도달 불가 및 SSH·Source·CLI 오류가 포함됩니다.

      경로 진단
      
        
      
          
      측정 대상에서 스위치 한 대와 목적지 한 곳을 선택하세요. 스위치가 최대 12홉을 조회합니다. 홉마다 프로브 1개, 대기 1초를 사용합니다.
      
          
          
      
          
      
          
      중간 홉이 응답하지 않아도 뒤쪽 홉에서 응답할 수 있습니다. L2 장비, ICMP 정책, 비대칭 경로는 이 결과만으로 판단하기 어렵습니다.
