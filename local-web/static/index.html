      케이블 진단

      구리 포트의 케이블 페어별 상태와 거리를 확인합니다.

      진단 대상

      포트·PoE 관리에서 변경

      
          
      
          
      진단을 시작하면 스위치의 이전 케이블 측정값을 지우고 선택한 포트를 새로 측정합니다.
      
        
      
      
      
      
      
        
      진단 결과
      
        
      대상 포트를 선택하고 케이블 진단을 실행하세요.
      
      
      
    
      
    
      
      
      IPV4 PING
      Ping 테스트
      스위치에서 서버까지의 IPv4 경로를 측정하기 위한 입력을 검토합니다.
      
      
      
        
      측정 대상 및 옵션
      개발 중 · 미리보기 전용
      
        
      
          
          
          
      
            
            
            
          
      
          
      
            
            
            
            
            
            
          
      
          
          
      옵션 도움말
      반복 횟수
      조합마다 전송할 ICMP 요청 수입니다. 장시간 모드는 추후 제공됩니다.
      Timeout
      CLI의 응답 대기 설정입니다. SSH 접속 시간을 포함한 전체 소요 시간과 다릅니다.
      Data Size
      ICMP 데이터 크기입니다. 공란이면 장비 기본값을 사용합니다. 큰 값은 경로 MTU에 영향을 받을 수 있습니다.
      Source
      SSH 접속 IP 또는 직접 IP/VLAN은 실제 장비 소유 여부를 실행 전에 확인해야 합니다. 자동 선택의 실제 출발지는 미리보기로 확인할 수 없습니다.
      동시성
      요청값과 실제 적용값은 다를 수 있습니다. 현재 개발 버전은 실제 동시성 1대로 제한합니다.
      
          
      
          
      장비에 접속하거나 Ping을 실행하지 않습니다.
      
        
      
      
      
      
      
        
      명령 미리보기
      
        
      입력을 작성하고 미리보기를 실행하세요.
      
      
      
    
      
    
      
      
      CONFIGURATION BACKUP
      스위치 컨피그 백업
      선택한 스위치의 설정 파일과 작업 보고서를 PC에 저장합니다.
      
      
      백업 대상
      스위치별 한 줄
      
        
        
      
        
        
      
        
      
      
      
      
      백업 결과
      완료된 백업이 없습니다.
      
    
      
    
      
      
      SSH CONNECTION
      SSH 접속 설정
      이 PC에서 스위치 접속에 사용할 계정과 호스트 키를 설정합니다.
      
      
      접속 계정
      계정 미설정
