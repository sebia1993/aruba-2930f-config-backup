# 로컬 웹 배포

이 폴더의 코드는 Windows에서 로컬 웹 서버로 실행한다. 운영 화면은 사용자가 열거나 스위치에서 수집한 실제 데이터만 표시한다. 테스트용 장비와 데이터는 tests에 둔다.

변경을 검증한 다음 main에 병합하고 병합된 커밋에 web-v버전 태그를 붙인다. 해당 소스에서 빌드한 Windows x64 ZIP과 SHA-256을 공식 GitHub Release에 게시한다. 게시 후 자산 해시를 확인하고 지정된 수신자에게 해당 버전의 공식 릴리스 페이지를 메일로 안내한다. 보낸편지함에서 링크를 확인해 중복과 누락을 방지한다.

배포 ZIP에는 가상의 장비·사업장·포트·전력값과 생성 코드를 포함하지 않는다. 의존 라이브러리의 테스트 자료도 배포에서 제외한다. 사용자가 저장한 원본 파일과 로그를 보존한다.
