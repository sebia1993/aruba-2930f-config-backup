# Aruba 2930F 기능 비교

로컬 웹 v1.29.0은 Aruba 2930F와 **Aruba 2930M-24G-PoE+ (JL320A)**를 지원합니다. 웹을 열면 **포트·PoE 관리**가 먼저 표시됩니다. 상단 또는 왼쪽 메뉴에서 **케이블 진단**과 **스위치 컨피그 백업**으로 이동할 수 있습니다. 스위치 IP만 입력하면 장비의 `show interfaces status`에서 확인한 물리 포트를 조회합니다. 링크 Up·Down과 PoE 지원 여부에 관계없이 표시합니다. IP 뒤에 포트 목록이나 범위를 입력하면 해당 포트만 조회합니다. 스위치별 포트 목록 조회 오류는 주소와 함께 표시됩니다. PC와 휴대폰 모두 조회를 시작하면 매트릭스가 화면 맨 위에 표시됩니다. 전체 실패 시 원래 입력값으로 대상을 수정할 수 있고, 매트릭스의 **조회 실패** 개수를 누르면 실패한 포트만 보이고, 다시 누르면 원래 보던 화면으로 돌아갑니다. 실패한 포트를 누르면 실패 이유가 보입니다. **이 포트만 재조회**로 하나씩 갱신하거나 **실패 포트만 재조회**로 실패한 포트를 한꺼번에 갱신할 수 있습니다. **결과 목록**은 스위치별로 포트 번호·전력 판정·실측 W·LLDP 이름을 보여줍니다. 두 보기를 전환하면 선택 포트와 필터가 유지됩니다. **전체 재조회**와 주기적 모니터링은 IP만 입력한 스위치의 현재 포트 목록을 다시 읽습니다. **선택 N포트 재조회**는 선택한 포트만 다시 읽습니다. 한 대의 포트만 점검할 때는 스위치 필터에서 장비를 고른 뒤 원하는 포트를 선택하세요. 매트릭스의 전력 상태별 개수를 누르면 해당 상태의 포트가 보이고 변한 타일에는 점선이 표시됩니다. **결과 목록**에서는 **전체 포트**와 **변화 포트 N개**를 전환합니다. 변화 목록의 네 열 안에서 달라진 항목의 직전값과 현재값을 비교할 수 있습니다. 필터나 페이지를 바꿔도 선택이 유지되며 제어 영역에 화면 밖 선택 개수가 표시됩니다. **대상 목록 관리**에는 대상 입력, 표 붙여넣기, 검증과 프로필 관리가 모여 있습니다. 매트릭스는 스위치 주소별로 포트를 묶고 번호순으로 표시합니다. 모든 타일의 크기와 포트 번호·LLDP 이름·링크 상태의 위치가 일정합니다. 긴 LLDP 이름은 가운데를 생략하고 이웃이 여러 대면 **이웃 N대**로 표시합니다. 타일을 누르면 포트 상세에서 스위치가 보고한 전체 이름을 확인할 수 있습니다. AP라는 근거가 확인된 이름과 유형 미확인 이웃 이름을 구분합니다. 타일 바탕색은 PoE 상태를 나타냅니다. 링크 상태는 초록 테두리와 **↑ Up**, 빨간 테두리와 **↓ Down**으로 표시하며, 이번 조회에서 링크를 확인하지 못한 포트에는 회색 테두리와 **—**가 표시됩니다. 포트 상세에서 **전력 추이**를 펼치면 최근 1시간·24시간·7일간의 실측 전력과 측정 시각을 확인할 수 있습니다. 포트 타일을 눌러 하나씩 고르거나 **전체 선택**으로 현재 범위의 포트를 고를 수 있습니다. 모두 선택하면 같은 버튼이 **전체 선택 해제**로 바뀝니다. 포트를 선택하면 전력 상태 필터의 **전력 미측정** 옆에 전원 버튼이 나타납니다. **Power OFF**를 누르면 선택한 포트의 전력 공급을 차단하고, **Power ON**을 누르면 공급을 켭니다. 마지막 선택을 해제하면 두 버튼이 숨겨집니다. 실행 후 같은 곳에서 전력 변화를 확인할 수 있습니다. **케이블 진단**에서는 같은 스위치 주소와 포트로 진단을 실행합니다. 스위치의 이전 케이블 측정값을 초기화한 뒤 선택 포트별로 이번 검사에서 읽은 페어부터 상태와 거리를 표시합니다. 네 페어 중 일부만 응답해도 확인된 수와 아직 값을 받지 못한 페어를 구분해 보여줍니다. **전체 포트 모니터링**은 입력한 모든 대상을 즉시 조회한 뒤 설정한 간격(1~60분, 기본 1분)으로 전력과 LLDP 정보를 갱신합니다. 진행 상황은 상단 진행바에서 확인합니다. **스위치 컨피그 백업**에서는 IPv4 주소를 한 줄에 하나씩 입력해 기본 SSH 포트 22로 접속합니다. 백업 파일은 이 메뉴에서 내려받고 포트 제어 결과는 **포트·PoE 관리**에서 확인합니다. **네트워크 공유**를 켜면 서버 주소에 연결할 수 있는 PC와 휴대폰에서 `서버IP:18766`으로 접속할 수 있습니다. 공유를 끄면 원격 연결이 종료됩니다.

실시간으로 PoE 설정을 확인한 포트는 AP 모델과 물리 링크 상태에 관계없이 **Power OFF**로 전원 공급을 끌 수 있습니다. **포트 비활성화**는 등록한 포트를 선택해 한꺼번에 실행합니다. 링크 Up/Down, LLDP의 AP 이름·모델, 전력값, 이전 조회 성공 여부는 선택 조건에서 제외했습니다.

아래 표는 이전 EXE와 웹 v1.2.0 당시의 기능을 대조한 기록입니다. 당시의 AP 로그 관제는 v1.12.0에서 종료했고, 스위치 단위 재조회 버튼은 v1.22.0에서 제거했습니다.

**비교 대상**은 Windows EXE v0.10.1의 기본 진입점인 NetworkManagerWindow와 로컬 웹 v1.1.0입니다. 오른쪽 열에는 이번 웹 v1.2.0에서 같은 작업을 수행하는 위치와 동작을 적었습니다. EXE는 공식 Windows x64 ZIP의 SHA-256을 대조하고 포함된 실행 파일을 오프스크린으로 시작했습니다. 메뉴 동작과 예외 처리는 배포 태그의 소스와 테스트로 대조했습니다.

v1.3.3부터 로컬 웹은 첫 접속에서 장비별 SSH 지문을 자동 등록합니다. 같은 IP와 SSH 포트에서 지문이 바뀌면 접속을 차단합니다.
