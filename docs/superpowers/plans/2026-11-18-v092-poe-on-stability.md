# v0.9.2 B안: 전체 선택 PoE ON 판별 안정화

## 목적
- v0.9.1에서 전체 선택 후 ON 버튼이 눈에 띄게 작동하지 않거나, 이미 ON 포트에 대해 불필요한 명령 전 검증이 반복되며 실패가 혼재하는 사용성을 개선한다.
- 사용자가 B안을 채택하여 코드 수정·자동 검증·main 병합 및 정식 릴리스를 명시적으로 승인했다.
- 실제 스위치 연결·복구 검증은 사용자가 별도 수행한다.

## 개발 범위
- ON 직전 선택된 모든 포트의 상태를 **ON 변경 필요 / 이미 ON / 확인 불가**로 구분한다.
- 이전 수집에서 이미 ON으로 보인 포트는 오래된 정보일 수 있으므로 해당 대상만 1회 읽기 전용 재조회한다. 이미 OFF가 확실한 포트는 즉시 재조회 대상에 넣지 않되, 변경 시점의 서비스 검증은 유지한다.
- 모든 체크 대상이 검증됐다면 OFF인 대상만 ON 제어 계획에 포함하며, 이미 ON으로 재확인된 대상은 명령을 보내지 않고 별도 집계한다.
- 확인 불가가 하나라도 있으면 전체 실행을 막는다. 자동으로 정상 대상만 골라 변경하지 않는다.
- ON 완료/실패 사유를 상태창과 요약에 표시하고 타이머가 이 메시지를 지우지 않도록 한다.
- OFF·포트 Down·단일 제어의 기존 안전 정책은 유지한다. PoE ON 후 AP 링크·무선 등록은 별도 검증한다.
- 기존 SSH 지문·장비명 검증, 승인, 결과 이력, 300포트 제한, 결과 불확실 시 자동 재실행 금지는 변경하지 않는다.
