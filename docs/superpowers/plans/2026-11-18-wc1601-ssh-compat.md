# Legacy SSH WC.16.01.0008 Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Follow RED → GREEN → verification.

**Goal:** Aruba 2930F WC.16.01.0008 장비에 대해 승인된 IP:포트만 세션 한정 `ssh-rsa` 호스트 키 협상을 허용하고 Windows 릴리스로 검증한다.

**Architecture:** `ssh_legacy.py` 메모리 allowlist가 `hostkeys.py`의 policy 함수에 주입된다. Paramiko 사전 프로브와 Netmiko 실제 인증 연결은 동일한 `target` 정책을 사용하며 GUI는 승인/해제 후 선택된 스위치의 읽기 전용 재조회만 실행한다.

**Tech Stack:** Python 3.14, PySide6, Paramiko 4.0.0 pinned, Netmiko 4.6.0 pinned, Windows CI/PyInstaller.

**Spec:** `docs/superpowers/specs/2026-11-18-wc1601-ssh-compat-design.md`

## Global Constraints
- 기존 SSH 지문 인증과 변경 차단, 포트 300 한도, AP535 OFF/Down LLDP 확인, 감사 이력, 자동 재시도 금지 유지.
- 기본 `ssh-rsa` 차단은 절대 변경하지 않음; 승인된 IP:포트에서만 host-key 예외, user pubkey는 차단.
- 신규 코드에서 비밀번호/토큰/장비 구성 로그 노출 금지.
- `main` 미병합·v0.9.4 별도 GitHub prerelease.
- 운영 장비로 자동 테스트하지 않으며 현장 검증 완료라고 주장 금지.

## Review Focus
- 승인되지 않은 endpoint가 예외의 영향을 받지 않는지.
- 최초 SSH 호스트 키가 신뢰 승인 전 사용되지 않고 변경된 지문은 계속 거부되는지.
- 사전 probe/인증 연결의 정책이 불일치하지 않는지.
- 취소/실패 시 auto retry·downgrade 또는 PoE 변경이 일어나지 않는지.
- 세션 해제 후 legacy allowlist가 확실히 지워지는지.
