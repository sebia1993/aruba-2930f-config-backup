# WC16.01 Automatic SSH Negotiation Implementation Plan

> For implementers: follow Superpowers RED → GREEN → complete Windows gate; no main merge.

**Goal:** Remove extra legacy authorization while preserving host key trust and safe PoE behavior.

**Architecture:** Add strict-then-legacy pre-auth `ParamikoHostKeyProbe.probe` with precisely one retry only for host-key negotiation incompatibility. Use existing session memory keyed by endpoint so authenticated Netmiko applies the same per-endpoint negotiated host-key policy. Remove redundant GUI and refresh existing docs/tests.

**Spec:** `docs/superpowers/specs/2026-11-18-wc1601-auto-ssh-design.md`.

## Constraints
- Auth credentials cannot be transmitted before SHA-256 host fingerprint trust is checked.
- Do not silently allow legacy KEX group1, SSH ciphers or RSA/SHA1 publickey authentication.
- Zero auto retries for configuration changes; only pre-auth SSH host-key probe may retry.
- CI full Windows tests, 80% branch coverage, signed? no — existing unsigned EXE ZIP integrity gates.
