# PoE 진행 상황 상단 고정 패널 설계 (2026-11-18)

## 목적
Aruba 2930F 포트 통합 관리에서 `전체 조회 → 범위 전체 선택 → PoE ON 즉시`의 사전 조회, 상태 판별, 실제 변경, 결과 확인 과정을 화면 이동 없이 관측한다. 운영자는 작업 중 어느 장비/포트에서 대기하는지와 명령 수행 결과를 구별할 수 있어야 한다.

## 승인된 방향: B안
- 포트 통합 관리의 상단, 조회 버튼 아래에 고정된 한 줄 상태 패널 배치.
- 조회 또는 PoE 제어가 시작되면 단계명, 현재 스위치 IP/포트, 진행 수/전체 수, 성공/이미 ON/실패/확인 불가의 집계를 보여준다.
- '상세 보기'를 눌러 포트별 최신 단계 및 검증 결과를 펼친다. 기본값은 접힘; 결과 테이블 폭을 줄이지 않는다.
- 첫 수집과 PoE 직전 읽기 전용 사전 재조회를 명확히 구분하고, 재조회/상태 판별을 실제 명령 전송으로 표시하지 않는다.
- 작업 단계: 조회 또는 사전 재조회 → 변경 필요/이미 ON/미확인 구분 → 포트별 SSH/설정 사전 검증 → 적용 및 사후 확인 → 완료/보류.
- 이미 ON은 실제 명령 미전송으로 명확히 표시하고, 전체 대상 중 확인 불가 1개라도 있으면 기존대로 일괄 제어 보류.
- 300포트 제한, PoE OFF AP-535/LLDP 안전 조건, SHA256 호스트키, 결과 불확실 시 자동 재시도 금지, 기존 작업 이력 형식과 소스 데이터 변경 금지.
- 백업 화면 및 전용 단일 제어의 안전 정책은 그대로 둔다.
- Windows 11 Python 3.14 / PySide6 테스트 및 CI가 통과해야 검증 완료로 본다.

## 배포 정책
`main`을 변경하거나 병합하지 않는다. 개발 브랜치에서 Windows 전체 검증 후 Windows x64 ZIP, SHA-256, SBOM을 포함한 GitHub **Pre-release**를 별도 태그로 발행한다. 실제 스위치 현장 검증은 운영자가 직접 수행한다.
