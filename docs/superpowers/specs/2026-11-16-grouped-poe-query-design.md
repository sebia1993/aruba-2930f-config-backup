# 다중 스위치·포트 전력 조회 C안

## 승인된 목적과 범위

사용자는 스위치마다 서로 다른 여러 포트를 입력하고 결과를 스위치별로 묶어 보는
계획 중 C안을 채택하여 구현을 요청했다. 직접 입력, 엑셀 표 붙여넣기, 조회 대상
목록 저장·불러오기, CSV 결과 저장을 포함한다. 이전 v0.2.0 단일 포트 제어는 유지한다.

검토한 대안은 A(직접 입력), B(A+표 붙여넣기), C(B+대상 목록 재사용)이며 반복 업무에서
목록을 재사용할 수 있는 C를 사용자가 선택했다. 실제 스위치 검증은 사용자 범위다.

## 사용자 흐름

메인 창의 `포트 전력 조회…`에서 별도 조회 창을 연다. 입력 표 한 행은 `SW IP`,
`SSH 포트`, `인터페이스 목록`, `이름(선택)`이다. 공통 계정·암호·선택 Enable 암호는
창에서만 사용한다. 스위치 추가/행 삭제, 표 붙여넣기, 목록 저장/불러오기를 제공한다.
붙여넣기는 탭 또는 CSV의 3열(IP, SSH 포트, 인터페이스 목록), 선택적 4열 이름을 받는다.
인터페이스 목록은 쉼표로 구분하며 `24`, `1/24` 같은 단일 식별자만 받는다.
범위, all, CX 3단계 식별자, 임의 명령은 받지 않는다.

목록의 키는 IPv4+SSH 접속 포트이며 각 행의 포트 대응 관계를 보존한다. 동일 접속
대상은 포트 목록을 순서대로 합치고 중복 포트는 제거한다. 입력 전체를 먼저 검증하며
잘못된 붙여넣기/파일을 일부만 적용하지 않는다. 서로 다른 비어 있지 않은 이름이
동일 접속 대상에 지정되면 사용자에게 정리를 요청한다.

`전체 조회`, `선택 스위치 재조회`, `선택 포트 재조회`, `조회 중지`, `CSV 저장`을
제공한다. 결과 트리는 접속 대상별 부모 아래 포트 행을 두며 접고 펼칠 수 있다.
부모에는 표시 이름/확인한 장비명, IP:SSH 포트, 처리/실패 개수를 표시한다.
행에는 링크, PoE 설정, 공급 상태, 실제 W, 조회 시각, 결과를 표시하고 상세 영역에는
관리 설정과 모델 등을 표시한다. 스위치나 포트 실패는 해당 범위에서 보여 준다.

조회한 값은 반환되는 즉시 표시한다. 재조회 대상 행은 시작 시 이전 값을 지우고 대기로
전환해 오래된 전력을 현재값으로 보이지 않게 한다. 다른 대상의 값은 원래 시각과 함께
유지한다. 입력 대상이 바뀌면 결과를 지운다. 누락/미지원/실패와 실제 0 W를 구분한다.

## 실행과 경계

스위치 간 동시 접속은 최대 3개, 한 스위치는 한 세션에서 포트를 순차 조회한다.
실제 장비 모델과 포트 존재 확인, SSH 지문 확인을 유지한다. 지문 저장/승인은 직렬화한다.
이름이나 장비명은 장비를 식별하는 키가 아니다. 동일 IP의 다른 SSH 포트는 별도 대상이다.
모든 조회는 기존 제한된 show 명령과 준비 명령만 사용한다. 설정 모드/변경/저장은 없다.
현재 관리자 EXEC/Enable 준비 요구를 유지하며 일반 계정 권한을 보장하지 않는다.

연결 15초, 명령 20초, 출력 1 MiB/10,000행, 자동 재시도 없음이라는 기존 한계를
재사용한다. 중지는 새 명령/대상 시작을 막고 현재 제한된 작업이 반환하면 세션을 닫는다.
인증/전송 실패 후 끊긴 세션은 재사용하지 않는다. 종료하지 못한 대상도 취소/실패로 남긴다.
조회 중 백업·단일 포트 제어와 동시 실행하지 않으며 부모 창 종료도 안전하게 처리한다.

초기 소프트웨어 한계는 접속 대상 100개, 대상당 인터페이스 384개, 전체 인터페이스
2,000개, 붙여넣기 100,000자, 목록 파일 1 MiB, 표시 이름 80자다. 이는 조회 규모를
제한하는 앱의 정책이며 하드웨어 능력이나 실제 포트 수를 뜻하지 않는다.

## 목록 및 결과 파일

목록 JSON은 `format: aruba2930f-poe-targets`, `version: 1`, `targets` 배열로 구성한다.
각 대상에는 `ip`, `ssh_port`, `interfaces` 문자열 배열, `label`만 저장한다.
최상위/대상에서 알 수 없는 키, 중복 JSON 키, 잘못된 타입/버전/크기/개수를 거부한다.
암호/계정/Enable 암호/조회 결과를 목록에 저장하지 않는다. 정상 확인 후 원자적으로
저장하고 실패 시 기존 파일을 보존한다. 파일을 불러오기만 해서는 접속하지 않는다.

결과 CSV는 UTF-8 BOM이며 포트 한 개가 한 행이다. 접속 주소/SSH 포트/이름/장비명/
인터페이스/결과/관리 설정/링크/PoE 설정/공급 상태/W/측정 시각/완료 시각/오류 정보를
포함한다. 측정값 없음은 빈 셀, 실제 0은 숫자 0이다. 문자열 셀의 수식 실행을 막는다.
시각은 파일에서 UTC ISO 8601, 화면에서는 로컬 시각으로 표시한다.

## 제외 범위

LLDP 추가 조회, 계정 저장/스위치별 별도 계정, 자동 반복 측정, Wh/kWh 추정,
일괄 전원 제어, 조회 화면의 직접 변경 동작은 이번 C안에 포함하지 않는다.
기존 단일 제어 창의 명령/승인 조건은 유지한다. 새로운 의존성은 추가하지 않는다.

## 검증과 배포

입력 대응 관계/중복/잘못된 파일/원자적 저장/CSV 수식 방어, 단일 세션 재사용/
병렬 제한/취소/부분 실패/명령 범위/지문 승인, 실제 Qt 입력·묶음·재조회·부모 종료를
자동 검증한다. 기존 전체 검사와 Windows 빌드/실행 점검을 통과한 뒤 v0.3.0
사전릴리즈로 배포한다. 실제 스위치 접속 없이 문서용 가상 화면을 생성한다.
