# 포트 통합 관리 GUI 개선 — A안 (상하 확장형)

## 변경 범위

기존 **포트 통합 관리** 화면은 입력 대상, 조회 결과와 제어 패널이 좁게 나뉘어 장비가 많을 때 IP·포트 목록을 대조하기 어려웠습니다. 아래 개선안은 **PySide6 실제 GUI 배치만 변경**하며 SSH/LLDP/PoE 파서와 장비 제어 서비스는 수정하지 않습니다.

- **상단**: **조회 대상 · SSH 접속 설정 펼치기**를 클릭하면 스위치 IP·포트 입력 표가 나타납니다.
- **중앙**: 입력 표와 포트 조회 결과를 상하(QSplitter Vertical)로 표시합니다. 구분선을 드래그해 입력 공간을 늘릴 수 있습니다.
- **입력 집중 모드**: **입력 크게 보기**를 누르면 결과 표시만 잠시 숨기고 입력 표가 세로 공간 전체를 사용합니다. **조회 결과 함께 보기**로 돌아올 수 있습니다.
- **조회 중심 모드**: 설정을 접으면 결과 표가 전체 가용 높이를 사용합니다. 체크한 포트와 수집 결과, 입력한 인증 정보는 접기/펼치기만으로 변경되지 않습니다.
- **대상 입력 표**: 고정 높이 150px와 컨테이너 높이 275px 제한을 해제했습니다. 스위치 IP 열은 읽기 쉬운 고정 초기 너비, 포트 목록 열은 가변 너비입니다.
- **하단**: PR #40에 이미 반영된 '선택 포트 상세' 제거, 기본 PoE OFF/ON 두 버튼 및 접힌 고급 제어는 그대로 사용합니다.

## 엑셀 붙여넣기 확대

- 대화상자의 초기 크기를 760×580에서 **1100×720**으로 확대했습니다. 창은 사용자가 크기 조절할 수 있습니다.
- 기존 상하 입력·검증 텍스트 영역을 **좌우 분할(QSplitter Horizontal)**로 바꾸고 가운데 구분선을 드래그할 수 있습니다.
- 오른쪽의 검증 미리보기는 IP, SSH 포트, 인터페이스 목록, 포트 개수를 **표 형태**로 보여줍니다.
- 기존에 첫 **40개 스위치**만 출력하던 제한을 제거했습니다. 검증에 성공한 **전체 스위치**가 스크롤 표에 표시됩니다.
- 원본이 변경되면 승인 버튼과 이전 미리보기가 즉시 무효화됩니다. 검증 오류가 있으면 기존 대상 목록은 변하지 않습니다.
- 기존 2열/3~4열 입력 형식, SSH 22 기본값, 동일 IP 포트 병합, 중복 제거, 추가/교체 모드 및 기존 한도는 유지합니다.

## 사용 방법

1. 포트 통합 관리에서 **조회 대상 · SSH 접속 설정 펼치기**를 클릭합니다.
2. IP와 인터페이스를 직접 입력하거나 **IP·포트 2열 붙여넣기…**를 선택합니다.
3. 붙여넣기 창 왼쪽에 엑셀 내용을 입력하고 오른쪽 **전체 미리보기**에서 스위치/포트와 오류 여부를 검토합니다.
4. **검증된 대상 적용**을 눌러 반영하고 스위치별 조회를 실행합니다.
5. 구분선을 드래그해 입력과 결과의 높이를 조절하거나 상단 입력을 접고 전체 너비·높이로 결과를 확인합니다.
6. 기존 안전 조건을 만족하는 포트를 명시적으로 체크한 다음 별도 PoE OFF/ON을 실행합니다.

## 충돌 관리 / 브랜치

- 본 UI 브랜치는 PR #40 (feat/port-vs-poe-status-v0.8)의 **검증된 HEAD를 기반으로 생성**했습니다.
- PR #40이 변경한 manager_gui.py와 같은 파일을 수정하므로 main에서 각각 독립적으로 재작업하면 코드 충돌 위험이 있습니다.
- PR #40은 포트 상태/PoE 상태 표시와 두 기본 제어 버튼, 상세 패널 제거 변경을 담당합니다. 이 브랜치는 **그 위에 상하 배치와 엑셀 입력 검증 UI를 추가**합니다.
- 본 브랜치는 원본 PR #40을 직접 수정하지 않습니다. 먼저 PR #40을 병합한 뒤 본 UI 브랜치를 최신 main 기준으로 확인·병합해야 중복 변경을 피할 수 있습니다.
