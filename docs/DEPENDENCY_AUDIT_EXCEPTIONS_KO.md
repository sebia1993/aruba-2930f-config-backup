# 의존성 감사 예외

이 문서는 자동 의존성 감사에서 일시적으로 제외하는 항목과 실제 실행 경로의
보완 통제를 공개합니다. 경고를 해결된 것으로 숨기기 위한 목록이 아닙니다.

## CVE-2026-44405

| 항목 | 내용 |
|---|---|
| GitHub Advisory | `GHSA-r374-rxx8-8654` |
| 대체 ID | `PYSEC-2026-2858` |
| 영향 의존성 | Paramiko 4.0.0 이하 |
| 현재 잠금 버전 | Paramiko 4.0.0 |
| 감사 심각도 | Low |
| 발견·검토일 | 2026-08-24 |
| 다음 재검토 기한 | 2026-09-24 |

Paramiko 4.0.0은 RSA/SHA-1 서명 방식인 `ssh-rsa`를 허용합니다. 상위 프로젝트는
커밋 `a4489456b6f65281e172380cc4826cee5e851dbb`에서 SHA-1 지원을 제거했지만,
2026-08-24 현재 GitHub Advisory에는 수정된 PyPI 버전이 제시되지 않았습니다.
따라서 의존성을 임의 Git 커밋으로 바꾸지 않고, 아래 보완 통제와 정확히 한 건의
감사 예외를 유지합니다.

## 보완 통제

- `disabled_algorithms`의 `keys`와 `pubkeys`에서 `ssh-rsa`를 비활성화합니다.
- 인증 전 호스트 키 사전점검과 실제 Netmiko 인증 연결이 같은 정책 함수를
  사용합니다.
- RSA/SHA-1 전용 서버는 사용자 이름이나 암호를 받기 전에
  `SSH_ALGORITHM_INCOMPATIBLE`로 종료합니다.
- SHA-256 호스트 키 지문을 별도 JSON 저장소에 고정하고, 변경된 키는 계속
  차단합니다.
- 보안 설정을 낮추는 자동 재시도나 대체 연결 경로를 제공하지 않습니다.
- 루프백 SSH 회귀 테스트와 생성된 연결 인자 테스트로 두 경로를 검증합니다.

`tools/validate.ps1`은 잠금 파일 감사에서 `CVE-2026-44405`만 제외합니다. 새 ID를
추가하거나 범위를 넓히려면 별도 보안 검토와 이 문서의 변경이 필요합니다.
GitHub Dependabot 경고는 수정 버전으로 교체할 때까지 열린 상태로 둡니다.

## 배포 경계

- 현재 `main`: 위 보완 통제가 포함됩니다.
- v0.1.8 Windows 바이너리: 위 보완 통제 이전에 생성되어 포함되지 않습니다.
- 자동 테스트와 루프백 검증은 실제 Aruba 2930F 현장 검증을 대신하지 않습니다.

## 예외 제거 조건

다음 조건을 모두 충족하면 감사 예외를 제거합니다.

1. Paramiko의 수정된 정식 PyPI 버전이 공개되고 Advisory에 수정 버전이 확인됨
2. `requirements*.txt`와 `pyproject.toml`을 같은 수정 계열로 갱신함
3. 호스트 키 사전점검, 인증 연결, 변경 키 차단과 Windows 패키지 검증을 통과함
4. `--ignore-vuln CVE-2026-44405`를 제거한 `pip-audit --strict`가 통과함
5. 보완 통제가 포함된 새 배포물을 만들고 SHA-256, SBOM, 출처를 검증함

재검토일까지 수정 버전이 없으면 Advisory와 PyPI 상태, 보완 통제 테스트 결과를
다시 확인하고 새 기한과 근거를 별도 PR로 기록합니다.
