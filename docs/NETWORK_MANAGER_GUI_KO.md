# Aruba 2930F 네트워크 통합 관리 화면 (v0.7.0 검토용)

## 목적

설정 백업 도구의 메인 화면에 포트 관리를 덧붙이던 구조에서 벗어나, **홈 / 컨피그 백업 / 포트 통합 관리 / 작업 이력 / 설정**을 동등한 왼쪽 탐색 메뉴로 제공한다.

## 화면 구성

| 메뉴 | 주요 내용 |
|---|---|
| 홈 | 컨피그 백업·포트 통합 관리로 바로 이동, 실행 중/마지막 작업 상태 |
| 컨피그 백업 | 왼쪽: 장비 IP·SSH 계정·저장 설정, 오른쪽: 실행·진행률·장비별 결과 |
| 포트 통합 관리 | 접을 수 있는 조회 대상/접속 입력, 중앙 포트 조회 결과, 오른쪽 선택 포트 상세·PoE/포트 제어 |
| 작업 이력 | 기존 result.xlsx와 일괄 포트 제어 JSONL을 읽기 전용으로 열람, Hostname과 IP 동시 표시 |
| 설정 | SSH 지문 관리, 이번 실행에서 적용할 기본 백업 저장 위치 |

컨피그 백업과 포트 통합 관리는 기존 서비스·실행 스레드·안전 제어 절차를 그대로 사용하며 화면만 옮긴다. 두 작업이 동시에 실행되거나 진행 중 화면 이동으로 결과가 사라지는 것을 막는다.

## 스위치 Hostname / IP 표시

- 컨피그 백업: 결과 표에서 IP, Hostname 별도 열
- 포트 통합 관리: 스위치 묶음의 **`Hostname · IP`**; 비기본 SSH 포트는 `(SSH 2222)` 추가
- Hostname 조회 전/실패: **`확인 전 · IP`**로 명시하고 절대 임의의 이름을 만들지 않음
- 선택 포트 상세: 실제 스위치 이름, 접속 IP·포트, 연결 AP, PoE와 LLDP 근거
- 작업 이력: 기존 파일에서 확인된 Hostname, IP를 별도 열로 표시

실제 대상 식별은 계속 **IP + SSH 포트 + 서버 키 지문**을 기준으로 하고 Hostname은 운영자 식별용으로만 사용한다.

## 포트 운영 편의 (v0.6.0 개발)

포트 관리 상단의 **IP·포트 2열 붙여넣기**는 SSH 설정이 접혀 있어도 바로 접근할 수 있다. 붙여넣은 대상은 적용 전 검증·미리보기가 표시되고 기본은 기존 목록 교체다.

포트 표의 조회된 전체·현재 스위치·검색 결과 범위 선택을 지원하고, 제어 가능만 선택은 기존 일괄 제어 안전 기준을 그대로 따른다. **전체 선택 자체는 제어 실행이 아니며**, 300포트를 넘는 일괄 제어는 제한된다.

PoE 재가동은 [단계별 운영 설명](PORT_OPERATOR_FLOW_KO.md)에 따라 각 단계에서 명시적으로 승인한다. OFF 확인 후 수동 재조회가 완료돼야 ON 계획을 만들며, ON 후 다시 현재 PoE 상태를 조회한다. 자동 재시도·자동 ON은 없다.

## B안 — 체크박스와 고정 PoE 제어 패널 (v0.7.0 개발)

- 장비와 포트 체크박스로 변경 대상을 명시적으로 선택하며 행 클릭은 포트 상세 정보 보기 전용
- 부모 스위치 체크박스에서 하위 포트를 모두 선택하며 일부만 체크하면 부분 체크로 표시
- 전체 선택은 등록된 모든 포트를, 현재 스위치 선택은 해당 스위치 전체 포트를, 검색 결과 선택은 보이는 포트만 포함
- 검색 필터가 바뀌어도 이미 체크한 포트를 유지하며 화면 밖 체크 개수를 따로 표시
- 하단 **PoE OFF/ON 즉시** 버튼은 별도 작업 계획 버튼이나 EXECUTE N 문구 없이 바로 실행 절차를 시작합니다. 단일 포트 OFF 및 ON은 클릭 즉시 시작하고, 다중 포트 OFF에는 오조작 방지를 위한 취소 가능한 확인창 1회만 표시합니다. 내부 불변 계획·SSH 지문·포트 재검증·JSONL 기록은 유지하며 빠른 경로는 10포트마다 추가 승인창을 반복하지 않습니다.
- 조회 결과가 없는 체크 포트는 자동 제외하지 않고 전체 실행 계획을 거부
- 작업 단계 중 체크·대상·필터 변경을 막고 OFF와 ON 각각 별도 승인 유지
- 사용자 HTML 미리보기를 검토하기 전에는 main에 병합하거나 공식 Release를 발행하지 않음

## 기본 화면 간소화 — v0.7.0 검토용

- 일반 포트 통합 관리 화면에는 체크박스와 하단 PoE OFF 즉시·ON 즉시·재가동 버튼을 기본 표시한다.
- 기존 `일괄 계획`, `EXECUTE N`, 단일 포트 상세 제어 및 포트 Up/Down은 **고급 제어 펼치기** 안에 보존한다. 기본값은 접힌 상태다.
- 기존 일괄 제어와 별도로 불필요한 작업 계획 승인 절차를 일반 사용자에게 노출하지 않는다. 내부 계획/감사 기록은 계속 작성한다.
- 실행 작업의 진행률·결과·중지 버튼은 고급 화면을 열지 않아도 하단 고정 패널에 나타난다.
- 백업/포트 화면 사이 전환 시 포트 SSH 입력란이 비어 있다면 백업 화면의 세션 중 계정·암호를 메모리에서 재사용한다. 디스크 저장하지 않고 개별 입력을 덮어쓰지 않는다.
- SSH 계정 권한과 최초 호스트 키 승인(새로운 장비)은 보안상 유지한다. 이미 신뢰한 지문은 그대로 재사용하며 변경된 지문은 차단한다.
- 다중 포트 PoE OFF만 한 번 확인하며, 빠른 ON/단일 OFF는 별도 계획·문자열 입력 없이 실행된다.

## 안전성 및 호환성

- 백업 `show running-config` 수집·결과 XLSX/TXT와 오류 재시도 정책 변경 없음
- 포트 조회는 기존 300개 스위치·14,400포트 논리 한도 및 CSV/JSON 대상 목록 유지
- 기존 단일/일괄 PoE OFF·ON, 포트 Down·Up 기능은 그대로 유지
- 위험 제어 실행 전 장비/포트 최신 재검증, `EXECUTE N` 확인, 작업 10개마다 재승인, 원자적인 JSONL 기록 유지
- 자동 PoE OFF→ON, 자동 재시도, 자동 롤백, `write memory` 기능을 새로 추가하지 않음
- SSH 비밀번호와 Enable 암호를 설정/결과 파일에 저장하지 않음
- 메인 창 전환/종료는 작업 스레드가 종료된 후에만 가능
- 새 이력 메뉴는 기존 저장 파일을 읽을 뿐, 새 데이터베이스·자동 이력 정리는 만들지 않음

## 사용 흐름

1. 프로그램 시작 후 홈에서 컨피그 백업 또는 포트 통합 관리 선택
2. 백업 화면: IP/접속정보 입력 → 백업 시작 → 결과 표에서 성공·실패 확인 및 폴더 열기
3. 포트 화면: 대상 입력 영역 펼침 → IP/포트 입력 또는 목록 불러오기 → 조회
4. 스위치 **Hostname · IP** 그룹에서 이상 포트 선택 → 상세/실측 W 확인
5. 오른쪽 단일 제어 또는 일괄 작업 계획 → 기존 명시적 승인 후 실행
6. 전원/포트 변경 후 수동 재조회, AP 이름/전력/링크 정보 확인
7. 작업 이력에서 결과 파일 확인

## UI 검증

Qt offscreen 기반 Windows 검증으로 홈·백업·포트 관리 화면을 캡처하고, 화면 탐색/대상 보존/이력 파싱/작업 중 화면 이동 차단에 대한 테스트를 실행한다.

**유의:** 시각 캡처와 자동 테스트는 실제 스위치에 대한 운용 안정성이나 전원 제어 성공을 증명하지 않는다. 실장비 검증은 운영자 별도 수행.


## v0.8.0 포트 조회 표 간소화 (개발 브랜치)

포트 통합 관리에 표시되는 열은 **스위치/포트, AP 이름(LLDP), 현재 전력(W), 포트 상태(Enable/Disable + Link Up/Down), PoE 상태(Power Enable/Detection Status)**입니다. 사용자에게 불필요한 ‘PoE 판정’과 ‘조회 상태’ 열은 제거했습니다.

다만 조회 실패, AP-535 협상 정보, 확인 전 설정, SSH 지문·기존 제어 계획은 내부적으로 보존합니다. 표의 상태 칸에 커서를 올리거나 포트를 클릭하면 이유와 측정 시각을 확인할 수 있습니다.
